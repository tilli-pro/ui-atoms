# Accessibility

Every story is checked with axe in CI, and any violation fails the build. There are no
per-story rule disables.

Open the **Accessibility** panel under any story to see the checks it passes. The component
fixes made to reach that state, with the rule each one answers, are recorded in
`apps/storybook/A11Y.md` in the [repository](https://github.com/tilli-pro/ui-atoms).
