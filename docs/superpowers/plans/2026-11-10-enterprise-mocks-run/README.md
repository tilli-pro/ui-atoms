# Enterprise mocks run record

- `ledger.md`: the subagent-driven run ledger (every ruling, parked item and deferred minor, per task).
- `fix-wave-brief.md`: the single fix wave after the whole-branch review.
- `check-recipe.mjs`: headless Playwright walkthrough used for verification. Run from the repo root with Node 22.22.2 against a dev server: `node docs/superpowers/plans/2026-11-10-enterprise-mocks-run/check-recipe.mjs http://localhost:5173 utilities,financial,government_federal "#/finance,#/finance/receivables" --interact`. It resolves Playwright from apps/storybook.

`--details` adds a profile pass per persona: for each of `#/network/contacts` and `#/network/organizations` it opens the first row's name link and records one JSON line `{ persona, route, h1, crumbs, badges, summaryCells, cards, tabs, tabErrors, overflowX, overflowAt1024, overflowInset }`. `tabErrors` holds the new console or page errors after clicking each tab; `overflowAt1024` re-reads horizontal overflow at 1024×800, and `overflowInset` opens the same profile on a fresh context at 1024×800 with the inset sidebar preset. Each profile counts as one page; a true overflow reading adds to `summary.overflowX`. Run it with `--interact --details` over `routes.txt`; the expected summary is `pages: 126` (120 + 6 profiles), `consoleErrors: 0`, `pageErrors: 0`, `overflowX: 0`, `failures: []`, and every profile line shows three crumbs, six summary cells, six tabs and empty `tabErrors`.
